# Iranian Localization

## Application Language

The product user interface is Persian.

## Layout

The application uses RTL layout by default.

## Calendar

The user interface uses the Solar Hijri / Jalali calendar.

## Database Date Storage

Business dates are stored as Gregorian ISO dates.

Examples:

2026-03-21

System timestamps are stored in UTC.

Examples:

2026-03-21T10:30:00Z

## Date Presentation

Dates are converted to Jalali for display and input.

## Currency

The primary accounting currency is Iranian Rial.

Amounts are stored in Rial.

Toman may be used only as a display option.

## Digits

The user interface may display Persian or English digits.

Database and API values use English digits.

## Documentation

- User interface text: Persian
- Source code: English
- Technical documentation: English
- GitHub documentation: English
