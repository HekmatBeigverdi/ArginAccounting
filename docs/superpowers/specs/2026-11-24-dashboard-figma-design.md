# Dashboard Figma implementation design

- **Intent:** Complete the desktop dashboard to match the Dashboard and Administration Figma frame (`25:31`) while keeping the existing RTL application shell and using real application data.
- **Goals:** Reproduce the Figma dashboard hierarchy and visual language (page heading, KPI row, trend panel, quick actions, and recent activity table); retain permission checks, empty/error/loading states, and working routes; keep layout responsive and token based.
- **Non-goals:** Change the shared shell or navigation, or add new backend/reporting contracts.
- **Constraints:** The current dashboard has active company/branch/fiscal context and a recent journal-voucher query. No dashboard aggregate source was found for sales, receipts, due payments, inventory valuation, or monthly trends. Match the supplied 1366 × 768 frame, including its 272px right sidebar, 148px shell header, and workspace card geometry. Keep the user's already modified App, router, login, and Tauri files untouched.
- **Approaches considered:** (1) Copy the Figma sample values, which matches the screenshot but may be mistaken for live company data; (2) use unavailable/empty states for unsupported metrics, which stays strictly data-backed but diverges from the requested design. **Chosen:** approach 1, as the user explicitly requested representative display data for statistics that are not available yet.
- **Implementation:** Refactor the dashboard and existing app shell (`app-shell.tsx`/`app-shell.css`) to reproduce the complete Figma frame: short accent strokes inside KPI cards, trend chart on the left and quick actions on the right, utility controls and active selectors in the header, and the logo, wave, icon-led navigation, and active-company card in the right sidebar. Keep recent vouchers data driven and permission gated; if the selected fiscal year has no entries, fall back to the latest company/branch vouchers across fiscal years. Use the implemented quick-action destinations. Fill unsupported metric and trend slots with illustrative Figma values in a presentation model that can later be replaced with live aggregates. Preserve responsive behavior and existing application data.
- **Approval:** The user approved implementation with illustrative statistics on 2026-11-24.
